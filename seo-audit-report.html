Verified against the live site. Several specialists analysed the local codebase, which is behind production. These stale/incorrect findings were corrected and should not be actioned:
  • “Homepage has no H1” — false; the live homepage has one keyword-rich H1.
  • “/about is full client-side render” — false; /about is server-rendered in production.
  • “/visas shows the attestation H1” — false positive; live H1 is correct.
  • “4 service pages missing from sitemap” — stale; production sitemap.xml already includes /hajj, /air-ticketing, /hotel-booking, /transport.
  • “Add HowTo schema” — rejected: HowTo rich results were deprecated (Sept 2023).
  • FAQPage won’t earn Google rich results for a commercial site (Aug 2023 restriction) — do it for LLM/AI citation, not Google snippets.

🔴 Critical — fix immediately

CriticalC1 · OG / logo image returns 404 sitewide

/og-default.jpg returns HTTP 404, yet it is referenced by og:image, twitter:image, and the schema Organization/TravelAgency logo. Every social share, WhatsApp preview and AI link card renders imageless, and the Knowledge Panel logo is broken.
Fix: add a real 1200×630 og-default.jpg to /public, plus a separate square logo for schema logo as an ImageObject.
Why it ranks here: a referenced asset 404s, degrading every external preview surface.  |  Failure check: curl -I /og-default.jpg ≠ 200.  |  Leading indicator: link previews show an image in WhatsApp/X.

CriticalC2 · Fabricated testimonials & unverifiable stats (YMYL trust)

13–22 hardcoded testimonials (initials only, no dates/source) plus a visible “4.9 rating” and “99% visa success rate” with no backing. For pilgrimage/visa (financial-decision) content, the Sept 2025 Quality Rater Guidelines treat this as deceptive.
Fix: replace with real Google Business Profile reviews (Places API or embed); add a methodology footnote to — or remove — the 99% claim.
Flagged by: content + local + SXO.  |  Failure check: any on-page rating still lacks a verifiable source.

CriticalC3 · Verify GBP primary category & start review velocity

GBP exists (CID confirmed in schema). Primary category is the single highest local-ranking factor and can’t be read from code.
Fix: confirm primary = “Travel Agency”; add “Tour Operator” and “Visa & Passport Service” secondaries. Launch a WhatsApp post-service review request (≥1 new review/week to beat the ~18-day decay cliff). Then wire the already-built aggregateRatingJsonLd() helper with real data.
Unblocks: AggregateRating rich snippet (depends on real review data).  |  Leading indicator: net-new Google reviews > 0 / month.

🟠 High — within 1 week

HighH1 · Thin listing pages can’t rank for high-volume terms

/tours and /visas are ~200–350 words of filter chrome + a card grid. Add a server-rendered 250–400-word editorial block, plus a 140–160-word question-led answer section (e.g. “How much do holiday packages from Hyderabad cost?”) above the grid. Must sit in the server component, not inside *Client.jsx.
Agreement: content + SXO + GEO — the biggest ranking ceiling on the site.

HighH2 · Rebuild /hajj as an informational-hybrid guide

Hajj 2026 SERPs reward guides (govt vs private quota, cost-by-category, documents checklist), not a service pitch. Add FAQPage JSON-LD (for LLM citation) and a TouristTrip with itinerary.
Flagged by: SXO — highest-potential keyword where structure alone could move ranking 10+ places.

HighH3 · Add verifiable credentials + a named team to /about

Add IATA agent code, TAAI membership number, Hajj-operator registration number, and 3–4 named consultants with roles/experience. Single biggest E-E-A-T lever.
Flagged by: content + SXO.  |  Strengthens: H1/H2 content rewrites.

HighH4 · Schema correctness fixes (src/app/layout.tsx)

  • sameAs URLs are missing the https://www. scheme → breaks entity reconciliation / Knowledge Panel.
  • Sunday openingHoursSpecification of 00:00–00:00 parses as “open 24h” → remove the Sunday entry.
  • Duplicate FAQPage on the homepage (FAQSection + FaqAccordion both emit) → keep one.
  • logo should become an ImageObject (after C1).
Flagged by: schema + GEO.

HighH5 · Sitemap hygiene (src/app/sitemap.ts)

Static routes use lastModified: now, so every URL looks “just updated” on every crawl — Google then distrusts lastmod sitewide. Use real per-route dates; drop changefreq and priority (Google ignores both). Dynamic routes already use real updatedAt — leave them.
Flagged by: sitemap.

HighH6 · Migrate email to the matching domain

sales@origingroups.com ≠ your website domain → fragments NAP/trust for directory validators. Move to sales@origintoursandtravels.com across site, schema, GBP and citations.
Flagged by: local.
